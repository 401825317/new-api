# 蓝绿发布运行手册

## 结论与适用范围

2026-09-06 已在 Zeabur 的两个独立 New API 实验服务上，通过 cf-global 真实入口验证新请求切流、旧 SSE 排空、旧实例停机和反向回切。仅使用管理员专用测试账号和模拟上游，没有切换客户路由。

本次两个实例都是 `v0.13.2-recovery-lab.3`，验证的是部署切换机制，不是不同版本间的数据库兼容性。正式服务不得使用含模拟上游的实验 Dockerfile。

## 常态与发布期间

- 常态：生产 A + 独立测试服务。
- 发布期间：生产 A + 生产 B + 独立测试服务。
- 排空与观察完成后：停止旧生产实例，保留其不可变镜像及回滚配置，恢复两个运行服务。
- 不把测试实例直接改造成生产实例；测试库和生产库始终分离。

## 正式发布检查表

1. 实时确认生产镜像版本与 digest、内网地址、真实数据库、Redis、卷及持久化数据位置；不能凭历史记录决定目标。备份必要数据及配置，密钥只进入受保护存储。
2. 将补丁应用到指定官方 tag，运行恢复测试、相关模块完整测试和 Linux race 检测。原共享 scanner 的旧路径 race 是已知独立问题，不能据此宣称整个仓库 race 全绿。
3. 比较 ORM 模型和自动迁移代码，而不只检查 migrations 目录。若需迁移，先在数据库副本演练兼容扩展与锁等待；避免破坏性迁移，旧版本必须仍可运行。镜像回滚不回滚数据库。
4. 构建不含 mock 的正式镜像并固定 digest。生产 B 使用同一生产数据库及必要的 Redis、SESSION_SECRET、CRYPTO_SECRET、模型配置和凭据；各字段按实际用途核对，不复制测试凭据。
5. 先确认 schema 就绪，再评估 B 以 `NODE_TYPE=slave` 启动。当前源码的该模式跳过自动迁移及部分主节点后台任务，但必须逐项核对所有任务的主节点约束/分布式锁。只停止旧 master 而不安排后续任务接管会遗漏后台工作。
6. B 完成 HTTP readiness、数据库/Redis 连通、管理员鉴权、真实上游单请求及计费冒烟测试。TCP 端口可连接不等于业务就绪。
7. 用专用 Key 做真实小流量验证。正式切流需要修改同一个 cf-global 生产账号的目标地址，必要时同时改上游 Key；这样保持账号 ID、组授权、并发计数和 cf-global 粘性不变。不要仅新增同优先级账号就认为全部流量已切换。
8. 更新必须具备精确旧值条件、事务和独立复核。同步处理该账号的 scheduler snapshot/outbox；从新请求的实例标记和日志确认实际落点，而不是只看数据库地址。缓存传播期间旧实例继续运行。
9. 旧实例停止接收新请求后继续服务已接入的 SSE。持续核对每个旧实例的在途请求、异步结算/任务、日志水位；确认均已排空才停止，不使用固定睡眠时间作为排空证明。
10. 观察新实例错误率、延迟、用量和渠道切换。回滚时只把新请求切回保留的旧实例，新实例已有输出的请求仍等待完成。不能把已输出内容的请求重放到另一实例。

## 正式启用前仍需补齐

- 生产级按实例统计的在途请求与结算排空判据。实验只通过受控 mock 的 active 状态、客户端完整终态和逐条账单交叉验证，不能直接替代生产观测。
- 同库、同 Redis、多版本/多实例环境中的迁移与后台任务单执行验证。实验两库独立，没有对此做生产兼容性背书。
- master 职责交接方案。若职责切换需要重启，必须先把用户流量保持在另一健康实例并排空待重启实例。
- 正式构建 provenance 与真实上游的小流量验证。模拟上游成功率不代表供应商容量。

## 本次实验结果

- 分支：`feauter/newapi-responses-recovery-lab`。
- 蓝实例长流跨越切流：56.953 秒、56 个连续片段，最大相邻片段间隔 1010 ms，只有一个正常终态。
- 绿实例长流跨越回切：54.399 秒、54 个连续片段，最大相邻片段间隔 1005 ms，只有一个正常终态。
- 绿实例接管、蓝实例完全停机后、反向回切后，各做 20 路并发，全部成功。
- 总共 66/66 次 cf-global 请求成功，无流错误；账单新增 66 条，实际扣费为 0。
- 测试账号 268 已恢复到蓝实例；正式客户账号 266 未修改。蓝实验服务和生产服务运行，临时绿实例已暂停。
- 详细证据及仅限实验的脚本位于工作区 `output/newapi-bluegreen-lab/`，脚本硬编码测试目标，不能直接用于生产。

## 停止条件

出现异常终态、缺片/重复片段、重复扣费、错误实例标记、路由写入影响行数不符、旧实例在途数量无法确认或迁移不兼容时，停止扩大流量。保留仍在服务的实例，不通过重启客户主入口尝试清缓存。
